可以用它做什么

  • 保存真实聊天，结合上下文回顾表达与沟通。
  • 准备虚拟对话练习，也可以轻松闲聊。
  • 与李聊天，查找历史档案，由模型选择适合记住的信息。
  • 回看练习反馈，写下自己的感受，通过 JSON 导入导出恢复已保存的档案。

开始体验

适用于 Windows 10 及以上的 x64 电脑，不需要在线注册，也不需要另外安装编程工具或数据库。请下载 EXE 安装包，在电脑上运行。

软件免费使用。首次打开后，在“模型与本地数据”中填写自己的完整接口地址、模型名称和 API Key，保存后测试连接。截图识别需要视觉模型，联网查资料需要检索服务，具体入口和说明见两份 TXT 附件。

模型和联网检索服务的费用由对应服务商收取。日记和档案保存在当前电脑；使用 AI 时，相关内容会发送给你配置的服务商，不会自动同步到其他设备。
